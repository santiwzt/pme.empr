# Pamela Rosales · sitio web

Sitio estático (HTML, CSS y JS sin dependencias) con clases, cursos, reuniones, videos y contacto para profesionales de la psicopedagogía y la psicología.

## Archivos

- `index.html`: toda la página.
- `img/pamela.jpg`: foto de "Sobre mí" y del inicio.
- `logo/`: logo e ícono en versión clara y oscura (SVG).

## Editar contenido

- Los textos de ejemplo están marcados con la clase `ph` (se ven resaltados en coral).
- Los cursos están en la lista `CURSOS` dentro del `<script>` de `index.html`. Para habilitar pagos más adelante, completar `precio` y `linkPago` en cada curso y aparece el botón "Inscribirme".

## Publicar gratis

Cualquier hosting estático sirve, sin build: GitHub Pages (repositorio público), Netlify, Cloudflare Pages o Vercel (planes gratuitos). Para usar un dominio propio después, se sube la misma carpeta.
